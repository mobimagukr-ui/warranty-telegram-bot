# Гарантійний Telegram-бот v2

## Додано у v2
- фото телефону/акта;
- Telegram ID клієнта для повідомлень про зміну статусу;
- сервісні центри з ID;
- автоматичне відстеження ТТН Нової пошти;
- статус ТТН у картці ремонту;
- CSV-експорт;
- історія статусів;
- нагадування про прострочені ремонти;
- ролі працівників/адміна.

### Встановлення
Python 3.10+:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

Скопіюйте `.env.example` в `.env` і заповніть BOT_TOKEN та ADMIN_IDS.

Запуск:
```bash
python run.py
```

### Нова пошта
Для автоматичного трекінгу створіть API key у бізнес-кабінеті Нової пошти та вставте його в `NP_API_KEY`.
Офіційна документація дозволяє інтегрувати відстеження відправлень через API.

### Команди
/start
/add
/search
/services
/addservice
/users
/adduser TELEGRAM_ID Ім'я

### Важливо
Поточна інтеграція ТТН використовує український API endpoint. Перед бойовим використанням перевірте ключ і формат відповіді вашого кабінету Нової пошти.
